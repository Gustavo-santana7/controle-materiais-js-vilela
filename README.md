# Controle de Materiais — JS Vilela Linhas e Cordas

## Sobre o projeto

Este projeto acadêmico tem como objetivo desenvolver um MVP (Produto Mínimo Viável) para auxiliar no controle de estoque e na movimentação de materiais da empresa JS Vilela Linhas e Cordas.

## Problema identificado

Atualmente, as saídas de materiais são registradas manualmente em um caderno. Algumas retiradas realizadas pelo setor de distribuição, especialmente as cordas utilizadas para amarrar as redes, não são registradas, provocando divergências no controle do estoque.

## Objetivo do MVP

Desenvolver uma aplicação web que permita registrar entradas e saídas de materiais, identificar os setores responsáveis pelas movimentações e consultar os saldos disponíveis.

## Funcionalidades previstas

- Cadastro de materiais.
- Cadastro de setores.
- Registro de entradas e saídas de materiais.
- Identificação da finalidade das movimentações.
- Consulta de estoque e histórico de movimentações.
- Registro de materiais utilizados na produção, conforme o escopo de desenvolvimento.

## Tecnologias planejadas

- Python
- Django
- HTML5 e CSS3
- Bootstrap
- PostgreSQL

## Arquitetura prevista

Arquitetura monolítica em camadas, separando a interface, as regras de negócio e a persistência dos dados.

## Situação atual

Fase de planejamento e prototipação. A implementação do sistema ainda será realizada.

## Finalidade acadêmica

Projeto desenvolvido como parte das atividades práticas do curso de Análise e Desenvolvimento de Sistemas.
